# 准点 Android

毫秒数字时钟与跨应用悬浮窗。1.1.0 起，首页、目标时间选择、悬浮位置、外观和设置均由 Kotlin 原生 Android View 构建，不再使用 WebView。悬浮窗和到点提醒继续由 Android 原生服务实现。

## 功能

- 两路 NTP 时间源校准后显示到毫秒，设置下一个整点或指定目标时刻并倒计时；校准不可用时明确退回手机时间。
- 跨应用悬浮窗，可拖动、调整尺寸与底色浓度、隐藏背景。
- 开启后在“悬浮位置”页直接显示原生悬浮时钟，可在实际屏幕上拖动定位，并用测试按钮检查触摸穿透。
- “防误触”同时锁定位置并让触摸穿透悬浮窗。
- 原生精确闹钟在目标时刻触发震动或提示音，不依赖悬浮窗或前台页面；设置页可测试提醒。通知栏可关闭悬浮窗。
- 首页和悬浮窗显示完整校准状态；设置页还显示手机时钟的估计偏差及测量延迟。打开应用、网络恢复及临近目标时自动更新，也可在设置页手动校准。

## 构建

Android Studio 打开本目录并构建 `app`。项目使用 Kotlin 1.9.25、Java 17、Android Gradle Plugin 8.9.2、compile SDK 36、target SDK 36。`./gradlew assembleDebug` 已通过。

本机另提供 `scripts/build-local.sh`，使用已缓存的 Kotlin 编译器和 Android SDK 的 `aapt2`、`d8`、`apksigner` 生成调试包，输出为 `dist/zhundian-debug.apk`。该脚本沿用先前测试包的本地调试签名，便于覆盖安装；不用于发布。标准 Gradle 调试包采用另一份调试签名，不能直接覆盖该本地测试包。

安装调试包后，在应用内点“开启悬浮时钟”，按系统提示授予“显示在其他应用上层”权限。授权返回后应用会自动开启悬浮窗并显示位置页；关闭防误触即可直接拖动定位。切到 App 的其他页面时悬浮窗隐藏，切到其他应用时继续显示。

Android 12 及以上首次使用到点提醒时，若首页显示精确提醒授权提示，进入系统页面允许“闹钟和提醒”。授权返回后会按当前目标重新安排原生闹钟。震动和提示音开关同时关闭时不安排闹钟；提示音使用系统闹钟音量。系统的勿扰模式、音量设置和厂商省电策略仍可能影响实际感知效果，建议抢票前用“测试提醒”确认。

## 注意

网络校准只调整应用内时间，不修改手机系统时间。NTP 样本受网络延迟和路径不对称影响，状态与偏差均为估计值，不能保证绝对毫秒级准确。首页和悬浮窗按屏幕帧刷新；临近目标时在支持的设备上请求高刷新率，但 60Hz 屏幕每帧约 16.7 毫秒，120Hz 每帧约 8.3 毫秒，无法显示每一个毫秒值。后台提醒仍受 Android 调度、音频和震动启动延迟影响。

Android 12 及以上对触摸穿透的悬浮层有透明度限制，因此防误触开启时整个悬浮窗透明度会限制在 79%。正式发布前还需完成多机型实测、发布签名及商店前台服务用途审核。
